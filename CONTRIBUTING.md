# Contributions

All changes to `main` must go through a pull request. Do not push changes directly to `main`, force-push it, or delete it. Only the human repository owner may merge pull requests; agents must leave them open for review. Preserve upstream license and copyright notices.

Initial repository creation and the unchanged upstream import establish the baseline. Subsequent changes require pull requests.

Private-repository rules require a supported GitHub plan. Until GitHub enforcement is available, this policy applies operationally. The prepared ruleset is stored in `.github/rulesets/main-pull-requests.json`; it must be activated and verified when the plan supports private rules or before publication.
